# Module 8 Assignment: Data Lookup with Dictionaries & Basic Aggregation
This repository contains my work for the Module 8 assignment in ISM2411 Python for Business. The assignment focuses on creating a customer
management system for GlobalTech Solutions using Python dictionaries and basic aggregation.

## Files Included
- 'module08-assignment' - Python program for managing customers, projects, services, budgets, and recommendations

## What I Practiced
In this assignment, I practiced using Python dictionaries to store and organize business data. I worked with nested dictionaries, dictionary 
methods, dictionary comprehensions, loops, conditionals, and functions. I also practiced basic aggregation by calculating totals, averages, 
minimums, and maximums for project hours and budgets.
